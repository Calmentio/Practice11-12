
# Пространственная кластеризация демографической структуры регионов России (2021)

**Практические работы № 11–12 по дисциплине «Анализ данных и машинное обучение» (АДиМО)**  
Магистратура · Команда № 3

## О проекте

Проект посвящён пространственной кластеризации субъектов Российской Федерации по четырём демографическим характеристикам за **2021 год**. Задача относится к **обучению без учителя**: готовые метки «правильных» групп отсутствуют, а структура территорий восстанавливается по внутренней неоднородности признакового пространства и по географической близости регионов.

Исследование отвечает на три вопроса:

1. Обладают ли демографические показатели регионов пространственной автокорреляцией, то есть похожи ли соседи друг на друга сильнее, чем случайные пары регионов.
2. На какие устойчивые территориальные типы распадается совокупность субъектов РФ по рассматриваемым характеристикам.
3. Какой из методов кластеризации даёт наиболее содержательное и устойчивое разбиение при одинаковых исходных данных.

**Цель** — получить воспроизводимое разбиение регионов на демографические типы, проверить пространственную структуру данных формальными индексами и обоснованно выбрать метод и число кластеров. Заранее предполагать превосходство какого-либо метода не разрешается: победитель определяется по заранее заданному составному правилу.

## Исходные данные

- **Объект исследования:** субъекты Российской Федерации, 2021 год.
- **Показатели:** ровно четыре характеристики демографической структуры (см. таблицу ниже).
- **Исключения:** сводные строки «Россия» и «федеральный округ» из совокупности удаляются.
- **География:** цифровая карта субъектов РФ (`ru.json`).

Полный журнал проверки ключей сохраняется в `results/join_audit.json` и подлежит обязательному просмотру.

## Методология исследования

### Пространственные веса

Строится симметричный граф **k = 4 ближайших соседей** по расстоянию между внутренними точками полигонов. Для несвязных компонент графа добавляются кратчайшие соединительные рёбра — все такие добавления логируются, чтобы структура соседства оставалась прозрачной и воспроизводимой.

### Пространственная автокорреляция

Вычисляются **глобальный и исследовательский локальный индексы Морана**. p-значения оцениваются по **399 перестановкам**; для локальных индексов применяется **поправка FDR** на множественное тестирование. Положительное значение I означает пространственное сходство соседей. Числовые значения индексов и p-значений по каждому показателю сохраняются в `results/global_moran.csv`.

### Сравниваемые методы кластеризации

Для каждого метода тестируется **3, 4, 5 и 6 кластеров**.

| Метод | Основная идея | Итог сравнения |
|---|---|---|
| **K-Means** | разбиение по расстоянию в признаковом пространстве, без пространственных ограничений | **победитель при k = 3** по составному правилу |
| **Spatial Ward** | агломеративная кластеризация с учётом графа соседства | не превзошёл K-Means по составному критерию |
| **MST spatial** | разбиение минимального остовного дерева | не превзошёл K-Means по составному критерию |

### Метрики сравнения

| Метрика | Направление | Смысл |
|---|---|---|
| Silhouette | выше лучше | качество разделения кластеров |
| Davies–Bouldin | ниже лучше | компактность и разделимость групп |
| Число территориальных компонент | меньше лучше | связность разбиения в пространстве |
| Устойчивость ARI при возмущениях | выше лучше | стабильность состава кластеров |
| Альтернативный RobustScaler | проверка | чувствительность результата к масштабированию признаков |

Победитель определяется **заданным в коде составным правилом**; это не теорема об абсолютном оптимуме. Полная таблица метрик сохраняется в `results/method_comparison.csv`.

## Основные результаты

### Пространственная структура

Глобальный и локальный индексы Морана рассчитаны для всех четырёх показателей; p-значения получены по 399 перестановкам, для локальных индексов применена поправка FDR. Числовые значения по каждому показателю приведены в `results/global_moran.csv`.

### Выбор модели

По составному правилу (Silhouette, Davies–Bouldin, число территориальных компонент, устойчивость ARI при возмущениях и проверка на RobustScaler) **побеждает K-Means без пространственных ограничений при k = 3**. Детальные значения метрик по всем методам и значениям k сохранены в `results/method_comparison.csv`, сводный статус — в `results/summary.json`.

### Содержательная интерпретация

- **Кластер 0 — полюса миграционного притяжения (10 регионов):** Камчатский край, Тюменская область, Республика Адыгея, Московская область, Ленинградская область, Краснодарский край, Республика Саха (Якутия), Калужская область, Калининградская область, Республика Крым. Отличительная черта — резко положительный миграционный прирост на фоне умеренной естественной убыли и повышенной рождаемости.
- **Кластер 1 — сжимающееся урбанизированное ядро (57 регионов):** самая многочисленная группа с наибольшим удельным весом городского населения и наиболее глубокой естественной убылью. Сюда вошло большинство областей центральной, северо-западной и восточной части страны. Именно этот кластер задаёт общий демографический тренд.
- **Кластер 2 — республики с расширенным воспроизводством населения (10 регионов):** Кабардино-Балкария, Северная Осетия — Алания, Карачаево-Черкесия, Бурятия, Калмыкия, Тыва, Чечня, Дагестан, Республика Алтай, Ингушетия. Характерны низкая урбанизация, положительный естественный прирост, максимальная рождаемость и миграционный отток.

**Главный вывод:** трёхкластерное решение K-Means разделяет регионы на миграционные центры, демографически сжимающееся ядро и республики с расширенным воспроизводством; оно устойчиво по совокупности метрик и признано лучшим по заданному составному правилу.

## Инструкция для запуска и воспроизведения

### Системные требования

- **Python 3.10+**
- **7-Zip** — для распаковки архивов с исходными данными.

### Автоматический запуск (Windows)

Запустите `Start_Windows.bat`. Скрипт последовательно скачивает источники, выполняет анализ и собирает материалы.

### Ручной запуск через терминал

```powershell
python -m pip install -r requirements.txt
python src/analyze.py
python src/build_materials.py
```

Для проверки работоспособности кода без обращения к реальным данным предусмотрен демо-режим:

```powershell
python src/analyze.py --demo
python src/build_materials.py --demo
```

В Windows он доступен через `Start_DEMO_Windows.bat`. Демонстрационный прогон проверяет код вычислений, а не соответствие реальным данным.

## Ограничения исследования

- Анализ использует **статический срез 2021 года**; выводы не описывают динамику демографических процессов.
- **7 несопоставленных регионов** исключены, поэтому разбиение покрывает не всю территорию страны.
- Схема **k ближайших соседей условна**: географическая близость по k точкам не равна общей границе полигонов, а результат может зависеть от способа выбора соседей и масштабирования признаков.
- На основании пространственных совпадений **нельзя делать причинно-следственные выводы**.
- В данных возможны отличия территориального состава и административных границ, поэтому результаты необходимо сверять с `join_audit.json`.
- Победитель определяется заданным в коде составным правилом и не является абсолютным оптимумом.
- Исследование носит учебный и аналитический характер и не является демографическим прогнозом или рекомендацией.
